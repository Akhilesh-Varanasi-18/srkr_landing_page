Myna — Project Color Palette

Extracted from the source design tokens of the Myna platform — the frontend education site (frontend/public/assets/scss/default/_variable.scss, Next.js + Bootstrap/Histudy theme) and the Admin dashboard (Admin/src/assets/scss/_variables.scss + _root.scss, Bootstrap 5.3 bs- theme). Both apps share one brand identity: a warm coral-red primary paired with an orange gradient. Dark mode is toggled via [data-theme="dark"] (frontend) and [data-bs-theme="dark"] (admin).
Shared brand token Admin dashboard only Frontend template only
